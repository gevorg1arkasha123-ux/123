# AI-видео бот — Telegram-бот + Mini App

Готовый бот для заработка на нейросетях, по образцу veo3 bot. Клиенты делают видео
по трендовым шаблонам и по описанию, оплачивают картой, СБП или Telegram Stars.
Вы получаете деньги, платите за нейросети и оставляете себе наценку.

## Что умеет

**Для клиентов** (приложение внутри Telegram):

| Раздел | Что делает | Нейросеть |
|---|---|---|
| Тренды (шаблоны) | Клиент выбирает тренд, загружает фото, и движения из образцового видео переносятся на него | Kling 3 Motion Control |
| Видео по описанию | Ролик со звуком по тексту, клиент выбирает «Стандарт» или «Премиум» | Kling 3 / Seedance 2 |
| Оживить фото | Фото превращается в видео, «Стандарт» или «Премиум» | Kling 3 / Seedance 2 |
| Повторить видео | Клиент сам загружает видео с движением и своё фото | Kling 3 Motion Control |
| Картинка | По описанию или редактирование своего фото | Nano Banana (Google) |
| Примерочная | Примерка одежды по фото | Nano Banana |
| Озвучка | Текст в голос | ElevenLabs |
| Аудио | Музыка и звуки по описанию | Stable Audio |
| Улучшить качество | Апскейл фото | Clarity Upscaler |

Ещё есть пополнение (карта, СБП, T-Pay, SberPay через ЮKassa, а также Telegram Stars), история генераций,
реферальная программа и подарочные монеты новичкам. Готовый результат бот присылает в чат.
Если генерация не удалась, монеты автоматически возвращаются.

**Для вас** (команды в боте, работают только с `ADMIN_IDS`):

- `/stats` — выручка, расходы на нейросети и прибыль за всё время и за сутки.
- `/prices` — цена, себестоимость и прибыль по каждому инструменту.
- **Новый тренд: просто отправьте боту видео** с подписью `Название | Категория | Подсказка`.
  Шаблон сразу появится в приложении.
- `/templates` — список шаблонов с кнопкой удаления.
- `/broadcast текст` — рассылка всем пользователям.
- `/give <id> <монеты>` — начислить монеты вручную.
- О каждой оплате бот присылает вам уведомление.

## Как устроены деньги

```
Клиент платит ₽ (ЮKassa) или ⭐ (Stars) → получает монеты → тратит на генерации
        ↓                                                      ↓
  деньги приходят вам                         вы платите fal.ai за нейросети (себестоимость)
```

**1 монета = 1 ₽.** Цена генерации считается сама: `себестоимость × курс $ × наценка (MARKUP)`.
При `MARKUP=2.5` и курсе 85 ₽ получается:

| Генерация | Себестоимость | Цена для клиента | Остаётся вам |
|---|---|---|---|
| Видео по шаблону-тренду | ≈ 60 ₽ | 149 ₽ | ≈ 89 ₽ |
| Видео по описанию, Стандарт | ≈ 43 ₽ | 107 ₽ | ≈ 64 ₽ |
| Видео по описанию, Премиум | ≈ 132 ₽ | 330 ₽ | ≈ 198 ₽ |
| Картинка (Nano Banana) | ≈ 3,4 ₽ | 9 ₽ | ≈ 5,6 ₽ |

Из «остаётся вам» вычитаются комиссия ЮKassa (около 3%), налог (4–6% для самозанятого или ИП),
бонусные монеты в пакетах и реферальные 10%. Остальное — ваша прибыль.

⚠️ **Себестоимость указана примерно.** Сверьте `falUsd` в `src/config.js` с ценами на страницах
моделей fal.ai перед запуском. Через `/prices` видно, сколько вы зарабатываете на каждой генерации.

## Запуск: пошагово

### 1. Что подготовить

| Что | Где взять | Сколько стоит |
|---|---|---|
| Токен бота | [@BotFather](https://t.me/BotFather) → `/newbot` | бесплатно |
| Ключ нейросетей | [fal.ai](https://fal.ai) → Dashboard → Keys, затем пополнить баланс | оплата по факту, нужна зарубежная карта |
| Сервер (VPS) | любой хостинг с Ubuntu, 1–2 ГБ памяти; лучше за рубежом (Нидерланды, Финляндия) | ≈ 300–600 ₽/мес |
| Домен (можно без него) | бесплатно: `IP-сервера-через-дефисы.sslip.io`, например `45-12-34-56.sslip.io`; или купить на reg.ru и направить A-запись на IP | 0 ₽ или ≈ 200–1000 ₽/год |
| ЮKassa | [yookassa.ru](https://yookassa.ru), подключается на самозанятого или ИП | ≈ 3% с платежа |

### 2. Установка на сервер

Подключитесь к серверу и выполните:

```bash
curl -fsSL https://get.docker.com | sh
git clone -b claude/telegram-video-bot https://github.com/gevorg1arkasha123-ux/123.git bot && cd bot
cp .env.example .env
nano .env      # заполните BOT_TOKEN, DOMAIN, PUBLIC_URL, FAL_KEY, ADMIN_IDS
docker compose up -d
```

HTTPS-сертификат для домена настроится автоматически. Откройте бота в Telegram и нажмите `/start`.

Обновить бота после изменений: `git pull && docker compose up -d --build`.
Посмотреть логи: `docker compose logs -f app`.

### 3. Подключить оплату картой и СБП (ЮKassa)

1. Зарегистрируйтесь в ЮKassa как самозанятый или ИП. Для самозанятого чеки в «Мой налог» ЮKassa отправляет сама.
2. В кабинете ЮKassa: **Интеграция → Ключи API** → скопируйте `shopId` и секретный ключ
   в `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`.
3. **Интеграция → HTTP-уведомления** → адрес `https://ваш-домен/webhook/yookassa`, событие `payment.succeeded`.
   Даже без этого шага бот сам проверяет оплату каждые 20 секунд.
4. Включите нужные способы оплаты (карты, СБП, T-Pay, SberPay) в настройках магазина.
5. `docker compose up -d`, и в разделе «Пополнить» появятся кнопки оплаты в рублях.

> **Про правила Telegram.** Официально Telegram требует продавать цифровые товары в ботах за Stars.
> Многие боты всё равно принимают карты через ЮKassa, но есть риск ограничений со стороны Telegram,
> особенно в версии для iPhone. Поэтому в боте работают оба способа: Stars и карта.
> Решите сами, оставлять ли оплату картой.

### 4. Добавить свои тренды

Найдите трендовое видео (3–30 секунд, до 20 МБ, в кадре один человек в полный рост)
и отправьте его боту с подписью:

```
Дьявол носит Прада | Тренды | Фото в полный рост, хорошо видно лицо
```

Готово: тренд в приложении, клиент загружает фото и получает себя в этом видео.
Используйте видео, на которые у вас есть права, или снятые вами.

Шаблоны хранятся в `data/templates.json`. Стартовый набор без образцовых видео лежит в `templates.default.json`:
он оживляет фото по промпту и годится для начала.

## Настройки (.env)

| Параметр | Что это |
|---|---|
| `MARKUP` | Наценка. 2 = цена вдвое выше себестоимости, 3 = втрое |
| `USD_RUB` | Курс доллара для расчёта себестоимости |
| `COIN_RUB` | Цена одной монеты в рублях (по умолчанию 1) |
| `START_BONUS` | Подарок новичку. 50 монет хватит на несколько картинок; чтобы было бесплатное первое видео, нужно ≥ 107 |
| `REF_PERCENT` | % монет пригласившему с каждой покупки приглашённого |
| `SUPPORT_USERNAME` | Ваш username для кнопки «Поддержка» |

Пакеты пополнения (цены в ₽ и бонусы) и модели нейросетей задаются в `src/config.js`.

## Проверить без затрат

Без `FAL_KEY` работает **демо-режим**: генерация имитируется, деньги не тратятся.
Для разработки на своём компьютере:

```bash
npm install
DEV_AUTH=1 npm start    # откройте http://localhost:3000 в браузере
```

На боевом сервере `DEV_AUTH` должен быть `0`.


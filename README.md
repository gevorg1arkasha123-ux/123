# AI-видео по шаблонам — Telegram-бот + Mini App

Бот в Telegram с встроенным приложением (Mini App), как у «veo3 bot»:

- **Главная** — лента «Тренды» с шаблонами видео: выбрал шаблон, загрузил фото, получил видео.
- **Что создадим?** (центральная кнопка) — инструменты:
  - Повторить видео (перенос движения с видео на ваше фото, Kling Motion Control)
  - Картинка (по описанию или редактирование вашего фото, FLUX)
  - Аудио (музыка/звуки по описанию, Stable Audio)
  - Примерочная (примерка одежды, FLUX Kontext)
  - Озвучка (текст в речь, ElevenLabs)
  - Улучшить качество (апскейл, Clarity Upscaler)
- **Пополнить** — оплата монет через Telegram Stars ⭐ (без банка и эквайринга).
- **История** — все генерации, просмотр и скачивание.
- **Профиль**.

Готовый результат бот также присылает в чат. Если генерация не удалась, монеты возвращаются.

Все нейросети подключаются через один сервис — [fal.ai](https://fal.ai), так что нужен только один ключ.

## Что понадобится

1. **Токен бота**: в [@BotFather](https://t.me/BotFather) → `/newbot`.
2. **Ключ fal.ai**: зарегистрироваться на fal.ai, пополнить баланс, создать ключ в *Dashboard → Keys*.
3. **Сервер с HTTPS**: Telegram открывает Mini App только по `https://`. Подойдут VPS + домен,
   Railway, Render, Fly.io и т.п. Для теста на своём компьютере можно использовать
   `cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000`.
4. Node.js 20+.

## Запуск

```bash
npm install
cp .env.example .env    # и заполните BOT_TOKEN, PUBLIC_URL, FAL_KEY
npm start
```

Откройте бота в Telegram и отправьте `/start` — появится кнопка «🎬 Открыть приложение»
(и кнопка меню слева от поля ввода).

Через Docker:

```bash
docker build -t video-bot .
docker run -d --env-file .env -p 3000:3000 -v $(pwd)/data:/app/data -v $(pwd)/uploads:/app/uploads video-bot
```

### Демо-режим

Если `FAL_KEY` не задан, генерация имитируется (через 4 секунды «готово»), деньги на fal.ai не тратятся.
Чтобы посмотреть интерфейс в обычном браузере без Telegram, задайте `DEV_AUTH=1` и откройте
`http://localhost:3000`. **На боевом сервере `DEV_AUTH` должен быть `0`.**

## Как добавить свой шаблон

Шаблоны лежат в `data/templates.json` (перезапуск не нужен):

```json
{
  "id": "my-template",
  "title": "Название на карточке",
  "category": "Тренды",
  "cost": 30,
  "duration": 5,
  "preview": "https://.../preview.mp4",
  "gradient": ["#7b2ff7", "#f107a3"],
  "emoji": "🎬",
  "hint": "Какое фото загрузить",
  "prompt": "Описание на английском, что происходит в видео. Keep the face identical"
}
```

- `preview` — ссылка на mp4/jpg превью; если пусто, карточка рисуется градиентом с эмодзи.
  Видео-превью можно положить в папку `public/` и указать как `/my-preview.mp4`.
- `prompt` — главное в шаблоне: что делает человек с фото. Пишите на английском.
- Можно указать `"model"` — другой эндпоинт fal.ai для этого шаблона, например
  `fal-ai/veo3/fast/image-to-video` (Veo 3, дороже, со звуком).

## Цены и модели

- Пакеты Stars и стоимость инструментов — в `src/config.js` (`packages`, `tools`).
- Там же поле `model` у каждого инструмента — можно заменить на любую модель fal.ai.
  Сверьте себестоимость генерации на fal.ai с ценой в монетах, чтобы оставаться в плюсе.
- Админ-команда `/give <user_id> <монеты>` — начислить монеты (ID админов в `ADMIN_IDS`).

## Структура

```
src/index.js     HTTP-сервер и API для Mini App
src/bot.js       бот: /start, оплата Stars, отправка результатов
src/generate.js  запуск генераций в fal.ai и опрос статуса
src/auth.js      проверка подписи Telegram initData
src/db.js        SQLite (пользователи, генерации, платежи)
src/config.js    настройки, цены, модели
public/          Mini App (HTML/CSS/JS)
data/            templates.json и база данных
```
